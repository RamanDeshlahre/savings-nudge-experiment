How value was projected

Six months were observed. Months 7 to 24 were projected from each customer's recent value, segment retention, and the chance they still move their salary in later.

Does the method work?

Because the data is simulated, the true effect is known. Observed 6-month effects match the truth in every segment. The 24-month projection picks the right segments but overstates the targeted-launch value by about 11%, and its intervals ignore model error.

Built with Python, SQL (dbt models) and a local SQLite warehouse; BigQuery-ready. All data is simulated and unit economics are illustrative assumptions.
